## 二、开发日志（按日期）

### 2026-10-26（周一）项目启动与基础功能 —— 🚩 M0 / M1 / M2

**今日进展**：初始化 Git 仓库，搭建 Flask 单文件应用和 Jinja2 模板目录，配置 Flask、SQLAlchemy、PyMySQL、dotenv、pytest 依赖。完成 User、Survey、Question、Option、Response、Answer 六类核心模型，建立用户、问卷、题目、选项、答卷和答案之间的关系。完成注册、登录、退出、问卷创建、填写链接、匿名填写、必填校验、截止时间、关闭和删除功能。

**遇到问题**：填写流程需要同时处理单选、多选、填空三种答案格式；匿名提交还需要判断是否重复。开发中采用账号或 Cookie 作为填写标识，具体问题记录见 DEBUG-001、DEBUG-002。

**产出**：可运行的 Flask + MySQL 项目骨架、基础页面、数据库模型、问卷创建和填写流程；完成 `README.md`、`.env.example`、`seed.py` 初版。

**里程碑**：M0 ✅；M1 ✅；M2 ✅。

### 2026-10-26（周一）统计、测试数据与首次归档 —— 🚩 M3

**今日进展**：完成统计结果页、ECharts 柱状图和饼图、填空答案列表、CSV 导出。增加 demo 测试账号和 12 条测试答卷，补充运行说明、设计文档、AI 协作记录和 Debug 日志。将基础版本提交到 Git，并推送到 GitHub 仓库 `L-YH2024/py`。

**遇到问题**：CSV 导出时 Flask 响应类与数据库 `Response` 模型名称冲突；Excel 中文兼容还需要 UTF-8 BOM，见 DEBUG-003。

**产出**：统计页、CSV 导出、测试数据脚本、项目说明文档和首次 GitHub 版本。

**里程碑**：M3 ✅。

### 2026-10-27（周二）填写端联调与多用户修复 —— 🚩 M4

**今日进展**：根据实际填写测试调整多选题校验，改为“至少选择一个”。修复同一 IP 下不同用户被误判为重复的问题：登录用户按账号区分，匿名用户按 Cookie 区分。控制面板增加“可填写问卷”列表，使新用户能够看到 demo 创建的开放问卷。补充问卷编辑入口和表单回显。

**遇到问题**：多选题给每个 checkbox 添加 `required` 会导致浏览器要求全部选中；同一浏览器登录两个账号会互相覆盖会话；已有答卷的问卷编辑题目时触发 MySQL 外键错误，见 DEBUG-004、DEBUG-005。

**产出**：多用户填写修复、可填写问卷列表、问卷编辑页面、已有答卷保护逻辑。

**里程碑**：M4 ✅。

### 2026-10-27（周二）统计验收与交付收尾 —— 🚩 M5

**今日进展**：将统计查询改为真正的 `GROUP BY + COUNT` 聚合；单选题保留柱状图和饼图，多选题改为横向条形图。根据课程要求核对 README、设计文档、开发日志、Debug 日志、AI 协作记录和报告材料，绘制 ER 图并插入已填写的课程设计报告。完成最后一次语法检查并推送到 GitHub。

**遇到问题**：原统计代码虽然能逐项调用 `count()`，但没有满足课程要求的分组聚合；原多选题图表使用普通纵向柱状图，见 DEBUG-006、DEBUG-007。

**产出**：交付版代码、ER 图、已填写报告副本、完整日志和 GitHub 仓库最新提交。

**里程碑**：M5 ✅。
